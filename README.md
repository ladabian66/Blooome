# Blooome

我的个人作品集网站 | My personal portfolio website

数字媒体艺术 × AI Coding —— 一个文科生的代码作品集。

**在线预览** → https://ladabian66.github.io/Blooome/

## 技术栈

- [Vite](https://vite.dev) + React + TypeScript
- [Tailwind CSS](https://tailwindcss.com) + [shadcn/ui](https://ui.shadcn.com)
- [Framer Motion](https://motion.dev) — 滚动视差与逐字动效
- [Skiper UI](https://skiper-ui.com) — 链接悬停动效（免费组件，按许可署名）

## 本地运行

```bash
npm install
npm run dev
```

## 部署

`main` 分支存放源代码；`gh-pages` 分支存放构建产物，由 GitHub Pages 发布。

```bash
npm run build   # 产物在 dist/
```
